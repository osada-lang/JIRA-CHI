# 提案用スライド・品質検証シート HTMLテンプレートの使い方

このフォルダには、ランサーズやクラウドワークスのプロジェクト提案時に「添付ファイル」として送信できる、高品質なPDF資料を生成するためのHTMLテンプレートが格納されています。

## 格納されているファイル
1. **`homepage_proposal.html`** : コーポレートサイトや複数ページのホームページ制作提案用の8枚スライド
2. **`lp_proposal.html`** : ランディングページ（LP）制作提案用の8枚スライド
3. **`qa_report_sample.html`** : テスト会社としての品質保証を証明する「品質検証チェックシート（A4）」
4. **`slides.css`** : スライドおよびチェックシートのレイアウトと印刷スタイルを制御するスタイルシート

---

## 📄 PDFへの変換手順（ブラウザからの保存方法）

Google Chrome または Safari を使用して、非常に簡単な操作で完璧な16:9比率（チェックシートはA4縦）のPDFを出力できます。

### 1. ブラウザで開く
Finderから各HTMLファイル（例：`homepage_proposal.html`）をダブルクリックするか、ブラウザにドラッグ＆ドロップして開きます。

### 2. 印刷ダイアログを開く
- Mac: `Command + P` を押します。
- Windows: `Ctrl + P` を押します。

### 3. 印刷設定を調整する（重要）
出力が崩れないよう、印刷プレビュー画面で以下の設定を行ってください。

#### 💻 スライド資料の場合（`homepage_proposal.html`, `lp_proposal.html`）
* **送信先（プリンター）**: 「PDFとして保存」または「PDFへ書き出し」を選択
* **レイアウト**: **横（Landscape）**
* **用紙サイズ**: A4 または レターサイズ（自動的に16:9でフィットします）
* **詳細設定（オプション）**:
  * **背景のグラフィック**: **必ずチェックを入れる（ON）** （これがないと背景色が消えて白黒になります）
  * **ヘッダーとフッター**: **必ずチェックを外す（OFF）** （ページ上部のURLや日付の印字を消すため）

#### 📄 チェックシートの場合（`qa_report_sample.html`）
* **送信先（プリンター）**: 「PDFとして保存」を選択
* **レイアウト**: **縦（Portrait）**
* **背景のグラフィック**: **チェックを入れる（ON）**
* **ヘッダーとフッター**: **チェックを外す（OFF）**

### 4. 保存する
「保存」をクリックし、デスクトップなどに保存します。出力されたPDFファイルをランサーズやクラウドワークスの提案画面に添付してください。

---

## ✍️ スライドやチェックシートのテキストを修正したい場合
テキストや実績URLを書き換えたい場合は、テキストエディタ（VS Codeなど）で直接HTMLファイルを開き、該当する文章のテキスト部分を自由に書き換えて上書き保存してから、再度上記手順でPDFを出力してください。
